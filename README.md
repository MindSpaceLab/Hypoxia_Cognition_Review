# Hypoxia and Cognition: Systematic Review and Meta-analysis

This repository contains the collated study-level data, R analysis code, and supplementary materials associated with the bioRxiv preprint examining the effects of hypoxia on cognitive performance.

The repository is provided to support transparency and reproducibility of the analyses reported in the preprint.

## Repository contents

| File | Description |
|---|---|
| `cog_ability_meta.csv` | Collated study-level data extracted for the systematic review and meta-analysis |
| `script.Rmd` | R Markdown file containing the statistical analysis code used in the preprint |
| `Supplementary Material 1.pdf` | Supplementary Material 1 associated with the preprint |
| `Supplementary Material 2.pdf` | Supplementary Material 2 associated with the preprint |
| `Supplementary Material 3.html` | Supplementary Material 3 associated with the preprint |

## Data

`cog_ability_meta.csv` contains the collated study-level data extracted from the studies included in the systematic review and meta-analysis.

The dataset contains the variables used in the statistical analyses reported in the preprint.

No individual participant-level raw data are provided in this repository.

## Analysis code

The statistical analyses were conducted in R using the `script.Rmd` R Markdown file.

The script contains the analysis workflow used to produce the results reported in the preprint, including the meta-analyses, moderator and meta-regression analyses, and associated figures and outputs.

The analysis code is provided to facilitate transparency and reproducibility.

## Reproducing the analyses

To reproduce the analyses:

1. Download or clone this repository.
2. Open `script.Rmd` in RStudio.
3. Ensure that the required R packages are installed.
4. Ensure that `cog_ability_meta.csv` is located in the same directory as `script.Rmd`.
5. Run or knit the R Markdown file.

The analysis code uses relative file paths so that the analyses can be reproduced without relying on machine-specific file locations.

## Supplementary materials

The supplementary materials provided in this repository contain additional tables, figures, analyses, and/or results associated with the preprint.

These files correspond to the analyses conducted using the collated dataset and R code provided in this repository.
